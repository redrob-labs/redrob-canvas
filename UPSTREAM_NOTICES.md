# Upstream source notices

Attribution for source code **vendored into this repository** from another project.

This is a separate file from `THIRD_PARTY_NOTICES.md` on purpose. That one is generated by
`tools/generate_distribution_artifacts.py` from the exact `Cargo.lock`, carries a "do not edit"
header, and is byte-checked in CI; it inventories *packages the build resolves*. Vendored source
is a different obligation with a different lifetime, so it is recorded by hand here and reviewed
whenever `docs/upstream-sources.toml` or `upstream-base.json` changes.

Only entries whose `kind` is `code` in `docs/upstream-sources.toml` belong here. Every one of them
is a git subtree under `crafts/`, squash-merged at the commit recorded below, with its own
`LICENSE-MIT`, `LICENSE-APACHE` and `NOTICE` left intact. The upstream copyright lines are never
replaced: ours sit beside theirs in `NOTICE` and `COPYRIGHT`, theirs stay as written.

Everything here is MIT OR Apache-2.0, the same terms as Redrob Canvas, so nothing in this
repository is bound by a licence other than the one on its own `LICENSE-MIT` / `LICENSE-APACHE`.
The Krita, GIMP, GEGL and Graphite material that earlier versions carried or translated was removed
in commit `d4854f2` together with the Qt shell; none of it remains, which is what made the
relicensing from GPL-3.0-or-later possible.

## How a subtree is updated

The same recipe for every entry; `<name>` is the directory under `crafts/` and `<sha>` the upstream
commit you are moving to:

```bash
git subtree pull --prefix crafts/<name> https://github.com/storytold/<name>.git <sha> --squash
python3 tools/merge_workspaces.py
```

Then record `<sha>` in `upstream-base.json` (`lastSyncedUpstream`), `docs/upstream-sources.toml`
(`commit`) and in the section below, in that order, and run `scripts/verify-upstream.sh`. The
merge commit is kept as a merge commit, never squashed into a working branch: a squash destroys
the subtree's merge base and the next pull replays work already taken. `scripts/fetch-upstream.sh`
runs the two commands above for you.

## photocraft

Copyright (c) 2026 ArtCraft Team and the PhotoCraft contributors. MIT OR Apache-2.0.

Vendored at `crafts/photocraft`, pinned at `ad96df566b587ebc056644c9e2bf621ddba39a92` of

## Brand assets are not open source

Each editor ships its brand under `crafts/<name>/docs/brand/` (`artcraft-logo*.svg`,
`artcraft-mark*.svg` and their PNGs) with its own `LICENSE-brand.txt`. The ArtCraft name, wordmark
and logos are trademarks of the ArtCraft Team. They are **not** covered by MIT or Apache-2.0, they
are kept in the tree only because the subtree carries them, and Redrob Canvas does not display,
install or package any of them. Redrob Canvas's own mark comes from the Redrob design system
(`DESIGN_SYSTEM_PIN.json`).
