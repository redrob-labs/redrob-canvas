# Upstream source notices

Attribution for source code **copied into this repository** from another project.

This is a separate file from `THIRD_PARTY_NOTICES.md` on purpose. That one is generated by
`tools/generate_distribution_artifacts.py` from the exact `Cargo.lock`, carries a "do not edit"
header, and is byte-checked at configure time; it inventories *packages we depend on*. Copied source
is a different obligation with a different lifetime, so it is recorded by hand here and reviewed when
`docs/upstream-sources.toml` changes.

Only entries whose `kind` is `code` in `docs/upstream-sources.toml` belong here. An `algorithm`
entry must not appear: reading a program to reimplement its behaviour creates no attribution duty,
and listing one here would misstate what this repository contains.

Why Apache and not MIT, recorded once so it is not re-litigated: Graphite ships no `NOTICE` file, so
Apache section 4(d) — the clause that would oblige us to carry and propagate upstream's own notice
text — imposes nothing. Section 3 then grants an express patent licence that MIT does not. Electing
the option carrying the patent grant therefore costs nothing and is worth having.

Apache-2.0 material is incorporated into a GPL-3.0-or-later work. That direction is permitted;
GPLv3 was drafted to accept Apache-2.0 terms. It does not run in reverse, so no code in this
repository may be redistributed under Apache-2.0 alone.

Modifications: the copied files are adapted to this product's rendering surface and naming. Per
Apache section 4(b), files carry a notice that they were changed. The renderer is **not** copied —
Graphite renders through wgpu and this product renders through Qt — so `node-graph/libraries/rendering/`
and every wgpu call site remain upstream-only.

1,169 lines across six files, bringing 7 upstream tests with them. Each file carries its own
Apache section 4(b) notice stating what was changed: module paths rewritten for this product's
shallower layout, and items raised from `fn`/`pub(crate)` to `pub` because upstream's only callers
were in files this tranche does not include. Three Poisson-disk helpers stayed private — they take
the accelerator's internal grid types, so exposing them would leak a private type through a public
signature.

Not yet ported from the same crate, and why: `bezpath_algorithms.rs`, `shapes.rs`,
`offset_bezpath.rs` and `merge_by_distance.rs` reach into Graphite's `core-types`; `gradient.rs`
(3,057 lines), `vector_attributes.rs` and `vector_modification.rs` carry its vector document
representation, which is the node-graph model this product does not have.
