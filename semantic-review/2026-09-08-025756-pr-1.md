# Sparse raster animation timeline end-to-end

이 변경은 stable frame CRUD, sparse per-frame raster cel, FPS-authoritative duration, range/loop playback, history-neutral navigation, Agent proposal tools, coherent FFI snapshots, Qt timer/model bridge, QML timeline controls를 하나의 경로로 연결한다. Core는 command마다 문서를 clone/apply/validate한 뒤 한 번만 commit하고, blank frame은 읽기에서 투명하게 보이되 첫 raster mutation 때만 저장 예산을 확인해 cel을 만든다. Rust/FFI/Qt smoke 검증은 모두 통과했고 이전 패스의 FPS-duration, canvas invalidation, Agent numeric narrowing, Qt move notification, timer smoke, transaction boundary 지적도 닫혔다. 그러나 playback 중 proposal Apply는 freshness 검사 직후 내부 navigation으로 generation을 바꾸고도 이미 검사한 proposal을 실행해 generation-bound 승인 계약을 우회한다. **Watch for: [Medium, confirmed] playback-stop과 proposal 실행 사이의 stale-check TOCTOU; [Low, confirmed] Qt random frame-ID 할당의 무제한 retry와 frame-limit 사전 차단 부재; [Low, confirmed] loop-end wrap의 자동 회귀 검증 부재.**

**Verdict**: NEEDS_CHANGES

## High-level view

Raster 내용은 `(node, frame ID)`로 분리되고 current frame에 cel이 없으면 renderer가 그 node를 투명하게 건너뛴다. Mutating raster command는 active node/current frame cel만 lazy materialize하며, duplicate는 `Arc` 기반 COW를 공유하되 저장 한도는 물리 allocation이 아니라 logical cel bytes로 선계산한다.

Frame add/duplicate/remove/move, FPS/range/loop는 typed `CommandBus` transaction과 history를 통과한다. Remove는 current frame과 range endpoint를 다음/이전 surviving frame으로 결정적으로 보정하고, move는 range endpoint 순서를 뒤집는 재배치를 거절하며, serialization validation도 FPS-derived duration과 frame/cel 관계를 다시 확인한다.

Current-frame 변경과 playback runtime state/tick은 history 밖에서 generation만 전진시켜 render와 proposal을 stale로 만든다. Undo/redo는 target snapshot에도 존재하는 viewed frame ID를 유지하고 그렇지 않으면 snapshot의 검증된 fallback을 사용하며, navigation은 redo stack을 지우지 않는다.

Agent는 mutating-only strict schemas와 immutable context로 typed proposal을 만들고 frame ID를 deterministic hash plus collision probe로 정한다. **[Medium, confirmed]** Qt Apply는 visible generation을 먼저 검사한 후 `executeCommand`/history action 내부에서 playback을 멈춰 generation을 변경하고도 같은 proposal을 실행하므로, 재생 중에는 stale proposal이 승인 경계를 통과한다.

FFI state JSON은 document/layers/timeline을 한 lock에서 만들고 owned output을 실패 전에 reset한다. Qt는 이 generation을 별도 render/selection snapshot과 대조한 뒤에만 model/image를 publish하며, FrameModel reset과 `timelineChanged`가 QML의 frame strip, range controls, boundary buttons를 갱신한다.

Qt의 local frame ID는 global PRNG에서 collision이 없어질 때까지 반복한다. **[Low, confirmed]** 반복 횟수 제한이나 `MAX_FRAMES` fast-fail이 없어 deterministic termination contract가 없다.

Core의 non-loop end-stop과 Qt의 실제 `QTimer` timeout/stop은 검증된다. **[Low, confirmed]** loop가 end에서 range start로 wrap하는 분기는 core, FFI, native smoke 어느 테스트도 실행하지 않는다.

## Sparse cel projection and logical storage accounting

Renderer는 current frame의 raster lookup이 missing이면 합성을 생략해 read-only render가 cel을 만들지 않는다 (`crates/redrob-core/src/render.rs:104-121`). Fill, clear, brush, gradient, filter, transform 계열은 `active_raster_pixels_mut` 또는 `prepare_active_raster_edit`로 current-frame cel을 확보하며, materialization은 canvas RGBA bytes를 document-wide logical storage에 더한 값이 1 GiB 이내인지 먼저 확인한다 (`crates/redrob-core/src/document.rs:760-792,1384-1486,1521-1619`; `filters.rs:10-14`). Selection과 group/raster mask는 frame-independent 상태로 남는다.

Duplicate는 source frame에 실제로 존재하는 raster cel만 clone하며 `RasterBytes`의 `Arc<Vec<u8>>`를 공유한다. 동시에 각 새 logical cel 길이를 quota에 합산하므로 COW가 저장 한도를 우회하지 못하고, destination 첫 edit에서 `Arc::make_mut`로 detach된다 (`document.rs:824-872`; `raster.rs:13-35,67-71`). 4096² canvas의 16번째 logical cel 거절과 destination-only detach가 regression으로 고정돼 있다.

Canvas crop/resize는 materialized cels와 masks의 aggregate target bytes를 먼저 계산하므로 sparse frame을 채우지 않는다. Existing selection, isolated groups, group masks는 core regression과 native hierarchy/mask smoke에서 timeline 경로와 함께 재검증된다.

## Frame relationships remain transactional across remove and move

`Editor::execute_internal`은 before에서 after를 만들고 command apply와 full validation이 성공한 뒤 generation, live document, history를 갱신한다 (`crates/redrob-core/src/editor.rs:518-529`). 따라서 duplicate ID/source/index, missing remove/move IDs, reversed/missing range endpoints, range-reversing move, logical-storage overflow는 중간 변경을 노출하지 않는다.

Remove는 current frame 삭제 시 오른쪽 survivor를 우선하고 마지막 위치에서는 왼쪽 survivor를 고른다. 삭제된 range start는 삭제 위치의 survivor로, range end는 직전 survivor로 clamp한 뒤 순서가 뒤집히면 한 frame range로 collapse한다. Raster node의 유일한 cel을 삭제하면 surviving current에 transparent cel을 만들며, 회수할 bytes와 재생성할 bytes를 함께 preflight한다 (`document.rs:874-956`). 테스트는 next/previous current fallback, range collapse/end clamp, failure transactionality를 다룬다.

Move는 temporary ordering에서 range endpoint position을 다시 계산하고 start가 end 뒤로 가면 `PlaybackRangeOrder`로 거절한다. FPS 변경은 모든 duration을 `round(1000/fps)`로 동기화하고 add/duplicate도 같은 값을 사용하며, load validation은 저장된 duration 불일치도 거절한다.

## History-neutral navigation and playback clock

Navigation은 active history group 중에는 거절되고 cloned document에 current/playing/tick 변경을 적용해 full validation 후 generation을 증가시킨다. `History::record`와 `clear_redo`를 호출하지 않아 current-frame 선택과 timer tick 뒤에도 undo/redo가 보존된다 (`editor.rs:531-563`). Playback 시작 시 current frame이 range 밖이면 range start로 이동하고 canvas invalidation도 before/after frame 비교로 보고한다.

Non-loop playback은 range end에서 playing을 false로 바꾸고 frame을 유지한다. Loop playback은 range start로 바꾼다 (`document.rs:1020-1058`). Qt는 FPS-derived precise timer로 `redrob_editor_advance_playback`을 호출하고 coherent refresh에서 playing=false가 보이면 timer를 중지한다.

**[Low, confirmed]** `crates/redrob-core/tests/timeline.rs`는 non-loop end-stop만 확인하고, `crates/redrob-ffi/tests/ffi_api.rs`는 tick 호출 성공만 확인하며, native smoke도 loop를 끈 뒤 timer stop만 기다린다. End에서 loop=true일 때 range start 이동, playing 유지, generation/history 불변 계약을 core test로 고정하고 가능하면 native smoke에서 timer active 상태까지 확인해야 한다.

## Generation-bound Agent approval has a playback-stop TOCTOU

Proposal creation은 immutable `ProposalContext`의 generation을 DTO에 넣고 provider tool metadata/arguments를 크기 제한과 strict decoding으로 검증한다. Frame IDs는 tool name과 provider call ID의 FNV-derived 시작점에서 existing context IDs를 linear probe해 retry가 동일하고 existing frame과 충돌하지 않는다 (`crates/redrob-ffi/src/graphics_tools.rs:1084-1199,1689-1711,1748-1845`). Provider response의 duplicate call IDs도 거절되며 Apply는 generation과 document epoch를 비교한다.

```text
applyProposal
  baseGeneration == m_generation   ✓
  -> executeCommand / executeHistoryAction
       -> stopPlayback()
            -> setPlaying(false)
                 -> core navigate: generation += 1
       -> execute command / undo / redo anyway
```

`EditorBridge::applyProposal`은 freshness를 먼저 검사한다 (`native/qt/EditorBridge.cpp:1557-1580`). 이후 command와 history helper는 `stopPlayback`을 호출하고 (`EditorBridge.cpp:384-444`), 재생 중이면 FFI navigation이 generation을 올린다 (`EditorBridge.cpp:552-583`; `crates/redrob-core/src/editor.rs:531-563`). **[Medium, confirmed]** 이 navigation은 architecture상 proposal을 stale로 만들어야 하지만 선택된 proposal은 재검사 없이 실행된다. 현재 stop은 frame을 바꾸지 않더라도 generation-bound approval invariant가 깨지고, future playback normalization이 추가되면 승인 당시와 다른 frame에 command가 적용될 수 있다.

Playback을 freshness 검사 전에 중지하고 새 generation과 proposal base가 다르면 Apply를 거절하거나 proposal 요청을 정지 상태에서만 허용해야 한다. 더 강한 해법은 expected generation을 받는 FFI `apply-if-current`로 check와 mutation을 같은 editor lock/transaction에 묶는 것이다. Native regression은 timer tick 전에 proposal을 만들고 Apply하여 stop navigation 뒤 stale action이 실행되지 않는지 확인해야 한다.

## Owned FFI snapshots and Qt publication coherence

Timeline/state/navigation ABI 함수는 output pointer를 받은 즉시 default buffer로 reset한다. `state_value`는 한 editor lock 아래 동일 generation의 document/layers/timeline을 직렬화하고, C header는 symbols와 ownership을 명시한다 (`crates/redrob-ffi/src/abi.rs:148-163,225-288,664-771`; `include/redrob_ffi.h:68-104`). Sentinel tests는 timeline/state/navigation을 포함한 owned-output 실패 reset과 C/C++ ABI symbol/layout을 검증한다.

Qt refresh는 coherent state 뒤 render와 필요한 selection snapshot을 획득하고 dimensions/stride/length와 모든 generation이 일치할 때만 models/images를 교체한다 (`native/qt/EditorBridge.cpp:1047-1208`). 불일치하면 세 번 재시도하고 projection을 stale로 표시해 edit, history, proposal creation/apply를 막은 채 timer refresh로 회복한다. Same-count frame move도 candidate current index 비교로 `timelineChanged`를 발생시켜 QML boundary bindings를 갱신한다.

## Qt frame-ID allocation can retry without a bound

Add와 duplicate invokable은 global PRNG 값을 뽑고 FrameModel의 모든 ID와 비교하는 loop를 중복 구현한다 (`native/qt/EditorBridge.cpp:453-483`). Timeline은 최대 10,000 frame이라 ID 공간 고갈은 불가능하지만, **[Low, confirmed]** repeating RNG에 대한 attempt bound가 없고 frame limit에서도 ID를 먼저 찾은 뒤 core rejection까지 진행한다.

공통 `allocateFrameId`에서 먼저 `frameCount >= MAX_FRAMES`를 거절하고 random 시도를 제한한 뒤 deterministic linear probe fallback을 사용해야 한다. Pure helper로 분리해 repeated collision, ID 0, near-limit, exact frame limit을 테스트할 수 있다.

## QML controls and native regression surface

QML frame strip은 stable ID로 navigation하고 duration/current/in-range를 model에서 읽는다. Previous/next, delete, move-left/right는 current index와 frame count 경계에서 disable되고 range ComboBox는 start<=end 선택만 제출한다 (`qml/Main.qml:483-621`). Range-crossing move는 core typed rejection을 받는다.

Native smoke는 production QML controls로 add/duplicate/delete와 양방향 move를 실행하고 버튼 경계, sparse transparent render, duplicate render, remove fallback, FPS duration, actual QTimer non-loop stop을 확인한다 (`native/qt/main.cpp:130-229`). 기존 selection, group-mask, raster capability smoke도 같은 실행에서 먼저 통과한다.

검증 결과는 `cargo test --workspace --all-targets` 113 tests, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --all -- --check`, Qt release build, CTest `redrob_native_smoke`와 `redrob_minimal_platform_smoke` 2/2가 모두 통과했다.
