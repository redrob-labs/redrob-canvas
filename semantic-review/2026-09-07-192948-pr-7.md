# Versioned v2 document model with COW raster history

The change introduces a validated v2 document model with timelines, frame-addressed raster cels, hierarchy metadata, node masks, and semantic text/vector placeholders while preserving literal v1 loading. Raster and selection storage become clone-on-write so transactional snapshots share unchanged bytes, while canvas operations cover every cel, mask, and selection. Validation is centralized at load, save, editor construction, and transaction commit with document-wide structural, semantic, and raster-byte budgets. **Watch for: confirmed, medium severity — semantic or grouped v2 projects loaded through FFI/Qt render as a successful transparent canvas instead of returning the typed unsupported-content error.**

**Verdict**: NEEDS_CHANGES

## High-level view

Project loading deserializes the envelope shape before selecting an isolated v1 wire model or the v2 document body. Unsupported versions are rejected before typed document decoding; v1 migration supplies the default timeline and default-frame raster cels.

Validation bounds dimensions, nodes, frames, hierarchy depth, raster bytes, metadata, semantic complexity, frame timing, playback references, masks, and cels. Parent/type/cycle checks and byte/complexity budgets apply across the complete document.

Raster clones share allocations and detach on mutation. Commands mutate and validate a candidate before publishing it, and history counts shared raster allocations once across retained snapshots.

Raster edits and rendering resolve the current frame. Crop and resize transform every cel and node mask plus the selection after preflighting aggregate target bytes; raster-only operations return typed errors for semantic content.

The remaining mismatch is at the C ABI: the legacy renderer consumed by Qt erases the new typed render errors and fabricates transparent pixels, allowing an unsupported v2 document to appear successfully rendered.

## Literal v1 migration and v2 envelope dispatch

`codec.rs:20-108` keeps the old `layers`, `active_layer`, flat pixel arrays, and selection body in dedicated v1 structs, then migrates them to root raster nodes with one default-frame cel and a default timeline. `load_project` checks `magic` and `version` before selecting a typed body (`codec.rs:115-133`), so version 99 with a structurally invalid document body returns `UnsupportedProjectVersion(99)`. Save validates and emits the v2 envelope.

Literal v1 migration, unsupported-version dispatch, deterministic v2 save/load/save, and v2 crop/resize roundtrip are covered. The repository has no commits or `main` ref and every source file is untracked, so compatibility could only be compared with the isolated wire structs and literal v1 fixture in this task, not a historical implementation.

## Document-wide limits and hierarchy invariants

`Document::validate` uses checked canvas/RGBA sizes and accumulates raster bytes and semantic complexity over the document (`document.rs:1266-1353`). Timeline validation rejects empty or oversized timelines, invalid fps/durations, duplicate IDs, missing current/range frames, and reversed ranges (`document.rs:1458-1503`). Hierarchy validation rejects missing parents, non-group parents, cycles, and paths beyond depth 256 (`document.rs:1505-1546`).

Raster nodes require bounded, unique, known-frame cels with exact RGBA lengths. Selection and node masks require exact canvas lengths. Metadata, names, text, vector paths/commands, semantic coordinates, node/frame counts, dimensions/pixels, and stored raster bytes are bounded. Crop and resize separately preflight all cels, node masks, and the selection against the target aggregate-byte cap (`document.rs:995-1021`).

## COW snapshots and transactional history

`RasterBytes` preserves byte-array serialization while storing `Arc<Vec<u8>>`; clones share storage and mutable access detaches (`raster.rs:9-76`). History walks selection, mask, and cel allocations and keys each by Arc identity, counting shared capacity once across before/after snapshots (`document.rs:1355-1431`, `editor.rs:93-159`).

`Editor::execute_internal` applies commands to a clone, validates the result, then increments generation, publishes, and records history (`editor.rs:404-414`). Failed commands cannot expose partial state. Group cancel restores the original snapshot, completed groups form one entry, and successful branch edits clear redo.

## Current-frame edits and whole-document canvas transforms

Active raster access, filters, and rendering resolve `timeline.current_frame`; missing cels and semantic active nodes return `MissingRasterCel` or `UnsupportedNodeContent`. Crop and resize iterate every raster cel, independently transform every node mask, and update the selection before committing dimensions (`document.rs:1023-1120`, `selection.rs:188-251`). Existing flat rendering, all command families, current-frame-only mutation, aggregate multi-cel resize rejection, deterministic transforms, selection behavior, and transactional failures are exercised in `editor_core.rs`.

## Semantic render errors disappear at the FFI/Qt boundary

**Confirmed, medium severity, blocking:** `RenderSnapshot::try_render` returns `UnsupportedNodeContent` for semantic or parented/grouped content (`render.rs:17-22`), and `Editor::try_render_snapshot` preserves it (`editor.rs:483-484`). `RenderSnapshot::render` instead catches every render failure and builds a transparent buffer (`render.rs:54-61`), exposed through `Editor::render_snapshot` (`editor.rs:491-493`). The C ABI calls that infallible method at `crates/redrob-ffi/src/abi.rs:602`, while `redrob_editor_load_rrg` accepts any model-valid v2 document at `abi.rs:662-663`. Text, vector, group, parented-raster, and missing-current-cel projects can therefore load and return `REDROB_OK` with blank pixels, which Qt treats as a coherent projection.

Use `try_render_snapshot()` in `redrob_editor_render_rgba` and map its error to `REDROB_ERROR`; this requires no ABI layout or signature change. Add an FFI test that loads valid semantic v2 content and asserts render failure plus a populated last-error string. Qt can then surface unsupported foundation content instead of publishing a blank image.
