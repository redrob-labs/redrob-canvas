# Bounded format adapters with strictness and atomicity gaps

The implementation routes RRG, PNG, JPEG, lossless WebP, ORA, and limited SVG through the Rust core, ABI-v2-compatible FFI, and distinct Qt project/interchange workflows. JPEG alpha and quality are explicit, frame export is nonmutating, imports use detached validated documents, parser work is bounded, and optional GEGL/Krita adapters report no product operations. ORA structure validation and failed Qt imports still violate the promised strict/atomic behavior, while the installed notice bundle remains explicitly incomplete for distribution. All Rust, OFF/OFF adapter, Qt 6.12, QML, native smoke, and install checks pass, but their assertions do not exercise these failures.

**Watch for:** **confirmed** — ORA accepts a root stack after the image element has closed; **confirmed** — a malformed or content-mismatched Qt open/import stops playback and increments generation before failing; **confirmed** — the install target packages a notice file that says the final transitive notice audit is outstanding; **confirmed** — parser security tests miss key attack-limit branches and sometimes pass on an earlier unrelated rejection.

**Verdict**: NEEDS_CHANGES

## High-level view

Generic raster routing is content-based, with extensions used only as expected-format hints. PNG and lossless WebP preserve RGBA, JPEG either rejects alpha or composites over an opaque matte with validated quality, and explicit-frame rendering does not navigate or touch generation/history.

ORA combines central-directory path checks, entry/expansion ceilings, DTD/entity rejection, blend/offset mapping, and detached document construction. **Confirmed:** it records that an image was seen but not whether it remains open, allowing malformed sibling or cross-nested stacks to become document hierarchy.

SVG is a data-only subset that rejects general browser features and external resources. **Confirmed:** several security regressions would escape the suite because fixtures already fail for empty documents or reject-loss policy and assertions accept any error.

The additive FFI preserves ABI v2 layouts, rejects aliased export destinations, resets outputs, decodes before replacement, and exports coherent document snapshots.

Qt separates `.rrg` identity from interchange, verifies content against suffix-derived expectations, bounds open-handle reads, and publishes with `QSaveFile`. **Confirmed:** it calls `stopPlayback()` before validation, so failed open/import is not atomic for playback and generation.

Optional adapter reporting remains truthful. **Confirmed:** packaging installs `THIRD_PARTY_NOTICES.md` even though it states that a complete transitive notice and corresponding-source audit is still required before binary distribution.

<details><summary>Details</summary>

## ORA root containment is not enforced by the XML state machine

`parse_stack_xml` sets `saw_image` on the first `<image>`, but `</image>` does not change state and `<stack>` only checks `saw_image`. A canonical ZIP containing `<image w="1" h="1"></image><stack><layer src="data/a.png"/></stack>` therefore imports as a one-node document. This is **confirmed** by an external focused harness against the current core, which printed `ACCEPTED 1x1 nodes=1`.

The bounded archive reader still prevents extraction, traversal, and entity resolution, but multiple top-level structures and cross-nested image/stack closures are silently interpreted as hierarchy. Track image-open/image-closed state, require the root stack to be a direct child while the image is open, and require exactly one matching image close after that stack.

## Failed Qt imports mutate playback before content validation

`replaceFromGenericBytes` calls `stopPlayback()` before invoking `redrob_editor_import_file` (`native/qt/EditorBridge.cpp:1447`). During active playback that navigation commits `playing=false` and advances generation (`EditorBridge.cpp:664-672`), so a renamed PNG opened as `.rrg`, malformed SVG, or other under-limit decode failure returns false after changing state.

This is **confirmed** from the call path. Native smoke only checks an oversized file rejected before `replaceFromGenericBytes` (`main.cpp:684-696`) and a valid project successfully opened during playback (`main.cpp:708-710`). The generic FFI can validate and replace directly; the new editor already forces playback off. Add a playback-active mismatch regression covering playing, generation, current frame, project path, undo, and redo.

## Security fixtures do not reach the claimed parser guards

Coverage is **confirmed** weaker than its test names imply. The external-image SVG fixture uses default `RejectLoss`, so it exits at `"SVG embedded raster import requires AllowLoss"` before testing the `https://` rejection (`svg.rs:738-754`, `tests/formats.rs:370-372`). Script and DTD fixtures have no supported node, so ignoring those constructs could still end in the empty-document rejection; all only assert `is_err()`.

ORA tests cover traversal, duplicates, and DTD content, but not the declared 8,192-entry, 512 MiB expanded, 256 MiB entry, 4 MiB XML, encryption, ZIP64, hierarchy-depth, or local/central consistency boundaries. Use otherwise-valid SVG fixtures, pass `AllowLoss` for external-image checks, assert `UnsupportedFeature`, and add exact/one-over ORA fixtures with typed failures.

## The installed notice bundle is intentionally unfinished

The install target copies the executable, GPL license, and `THIRD_PARTY_NOTICES.md`. The notice lists quick-xml, svgtypes, zip, and font8x8, while the lockfile also contains the directly used image codec stack (`image`, `image-webp`, `png`, `zune-jpeg`, and transitives). It explicitly says a generated transitive notice and corresponding-source bundle remain required and that the focused notice does not replace the distribution-time audit.

This is a **confirmed** release gate, not a hidden documentation error. Generate and install the final lockfile/Qt/native inventory and corresponding-source obligations, or make that generation mandatory before a distributable install/package target succeeds.

## Validation results and remaining blind spots

`cargo test --workspace` passed 170 tests, including 17 focused format and 18 public FFI tests. Formatting and strict workspace Clippy passed. Fresh OFF/OFF adapter-only and Qt 6.12 builds passed CTest, QML lint, offscreen smoke, and minimal-platform smoke; installation produced the binary and both declared license files.

These checks cover lossless PNG/WebP pixels, JPEG policy, immutable frame export, builder validation, deterministic ORA export, SVG round-trips, FFI ownership/reset/ABI parity, Qt route identity, bounded reads, atomic writes, and default adapter truthfulness. They do not cover the malformed ORA acceptance, failed-import mutation, parser branches, or distribution gate above.
