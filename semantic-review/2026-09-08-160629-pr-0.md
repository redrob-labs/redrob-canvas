## Playback stopping is part of the successful Rust transaction

`Editor::execute_internal` applies to a clone, stops playback on that candidate, validates it, and only then advances generation, replaces the document, and records history (`crates/redrob-core/src/editor.rs:569-580`). Undo and redo validate cloned targets before moving either history stack and stop playback only on the committed target (`crates/redrob-core/src/editor.rs:647-709`). Failed commands, unavailable history, and invalid targets cannot alter editor state.

The bridge calls command/history FFI before stopping its Qt timer (`native/qt/EditorBridge.cpp:453-516`). Proposal freshness is checked before dispatch, so a current proposal reaches the same atomic path without a preliminary generation change (`native/qt/EditorBridge.cpp:1988-2025`). Native smoke coverage exercises active-playback Apply, stale and invalid proposals, rejected direct commands, unavailable redo, and successful undo while comparing playback, generation, frame, FPS, history, project path, render, proposal count, and timer stability (`native/qt/main.cpp:514-663`).

## Generic imports and ORA containment commit only complete replacements

`redrob_editor_import_file` parses bounded options, decodes the complete file, serializes result metadata, and constructs a validated stopped `Editor` before replacing the locked live editor (`crates/redrob-ffi/src/abi.rs:1237-1272`). Qt does not stop playback before this call and updates document epoch, projection, and project identity only after success (`native/qt/EditorBridge.cpp:1428-1487`). FFI state-equality and native failed-open regressions cover malformed options, format mismatch, and active-playback preservation.

The ORA state machine permits exactly one closed `image` and one root `stack`, with layers/groups only under the open stack. Cross-nesting, sibling roots, missing/unclosed roots, and trailing elements are typed failures (`crates/redrob-core/src/ora.rs:475-652`). Entry count, expanded and per-entry bytes, XML bytes, hierarchy depth, encryption, ZIP64, multidisk, paths, duplicates, and local/central consistency are bounded. Tests assert malformed containment and exact typed parser boundaries (`crates/redrob-core/tests/formats.rs:313-401`, `crates/redrob-core/src/ora.rs:805-1030`).
