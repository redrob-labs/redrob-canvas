# Generic format routing across FFI v2 and the Qt product shell

The implementation routes RRG, PNG, JPEG, lossless WebP, ORA, and limited SVG through strict FFI-v2 JSON options, separates editable project identity from interchange workflows, and keeps optional GEGL/Krita surfaces explicitly non-operational. Import replaces the editor only after decode, export encodes from a coherent snapshot, and Qt publishes through `QSaveFile` without changing project identity or timeline state. Two native boundary defects remain.

**Watch for:** **confirmed** — aliased `out_bytes`/`out_result_json` pointers create overlapping Rust mutable references and can leak the first returned allocation; **likely** — `QFileInfo::size()` followed by unbounded `QFile::readAll()` lets a changed or size-indeterminate file bypass the intended 64 MiB native read bound.

**Verdict**: NEEDS_CHANGES

## High-level view

The generic ABI is additive and maps strict schema-v1 options to core import/export behavior. Its two-output export helper assumes distinct destinations without documenting or enforcing that precondition, leaving a public C call capable of triggering Rust aliasing undefined behavior.

The Qt bridge distinguishes RRG project paths from interchange files, verifies content against extension-derived hints, and stops playback before replacement. Its size check is not coupled to the bytes actually read, so the host can allocate beyond the stated limit before the core rejects the payload.

QML exposes explicit loss, JPEG quality, and opaque matte controls, while native smoke verifies the advertised interchange routes and non-navigating frame export. The adapter libraries and documentation keep compilation/lifecycle facts separate from readiness and continue to advertise no GEGL or Krita product operations.

## Export result ownership is unsafe when C destinations alias

`redrob_editor_export_file` passes both destinations into `reset_two_buffers`, which resets each raw pointer and then converts both to simultaneously live `&mut RedrobBuffer` references (`crates/redrob-ffi/src/abi.rs:281-298`, `crates/redrob-ffi/src/abi.rs:1263-1307`). The public header requires writable pointers but not distinct pointers. Passing the same address violates Rust's exclusive-reference invariant; if execution continues, writing encoded bytes and then result JSON into the same slot also loses the first allocation.

This is **confirmed**. Reject equal non-null pointers before constructing references, reset the shared destination once, and return `REDROB_ERROR`; alternatively keep raw pointers until distinctness is established. Update `redrob_ffi.h` and add a C-facing regression that passes one destination twice and verifies an error plus `{NULL,0}`.

## Metadata preflight does not bound the bytes read by Qt

`openProject` and `importFile` compare `QFileInfo::size()` with 64 MiB, then open the path and call `file.readAll()` (`native/qt/EditorBridge.cpp:1491-1500`, `native/qt/EditorBridge.cpp:1517-1526`). A file can grow or be replaced between those operations, and size-indeterminate local devices can report a non-positive size. The core rejects oversized content only after Qt has allocated and read it.

This is **likely** to permit memory exhaustion for a changed or size-indeterminate selected path. Read at most `kMaxFormatInputBytes + 1` from the opened handle, reject the extra byte, and report read errors separately. Add a helper-level fixture whose readable length exceeds 64 MiB without relying on preflight metadata.

## Boundary cases missing from otherwise broad format coverage

The 18 product FFI tests cover generic roundtrips, strict options, expected-format mismatch, atomic import failure, JPEG alpha policy, explicit-frame nonmutation, ordinary output reset, capability truthfulness, and C11/C++17 contracts. Native smoke covers PNG, WebP, JPEG with matte, ORA, SVG, project identity, playback stop, and export nonmutation. Not tested: one address used for both export outputs, and readable input exceeding the metadata preflight.
