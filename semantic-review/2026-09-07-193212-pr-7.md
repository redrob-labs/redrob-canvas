# Typed FFI failure for unsupported v2 rendering

The C ABI renderer now preserves the core renderer’s typed failure for semantic and grouped v2 documents instead of returning a transparent image as a successful render. It clears the caller-owned snapshot before rendering, routes through `Editor::try_render_snapshot`, and lets the shared ABI boundary translate `CoreError` into `REDROB_ERROR` with a populated thread-local last-error message. The new integration test proves that a model-valid semantic v2 project loads successfully but cannot be rendered through the raster-only projection. **Watch for: no blocking concerns remain from the task #7 v2 foundation review.**

**Verdict**: APPROVED

## High-level view

The render boundary now has one error-preserving path from core to C: unsupported node content remains an error through `Editor`, string conversion, and `ffi_call`, while the public ABI signature and snapshot layout remain unchanged.

Failure leaves no stale projection behind. The ABI zeroes every snapshot field before validating the editor or attempting rendering, so callers cannot mistake old dimensions, generation, or pixel ownership for a new image after `REDROB_ERROR`.

The regression fixture separates document validity from renderer capability. Its semantic v2 document passes `redrob_editor_load_rrg`, then render returns `REDROB_ERROR`, leaves a default snapshot, and exposes the unsupported-operation message through last-error.

## Fallible rendering survives the C ABI boundary

`redrob_editor_render_rgba` resets `out_snapshot` to `RedrobRenderSnapshot::default()` before editor lookup and rendering, then calls `lock_editor(handle).try_render_snapshot()` rather than the compatibility `render_snapshot()` method. The returned `CoreError` is converted to its display text and passed to `ffi_call`, which returns `REDROB_ERROR` and stores that text in `LAST_ERROR`. No buffer is allocated until rendering succeeds, so failure cannot expose a partial snapshot.

`Editor::try_render_snapshot` delegates to `RenderSnapshot::try_render`, which rejects semantic nodes and parented/grouped content. The C boundary now preserves that rejection without changing ABI layouts or signatures.

## Semantic v2 validity is tested separately from raster projection support

The FFI integration test starts from a serialized v2 document produced by `save_project`, replaces the root content with a bounded text payload, and requires `redrob_editor_load_rrg` to return `REDROB_OK`. It then seeds every output field with non-default sentinels and requires `REDROB_ERROR`, a null/empty RGBA buffer, zero dimensions, zero stride, zero generation, and an unsupported-raster-operation last-error message.

This distinguishes a model-valid semantic document from malformed input and covers both the former transparent-success behavior and stale output after failure.
