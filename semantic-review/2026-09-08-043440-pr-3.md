## Typed semantic commands and decoded projects share one limit contract

`validate_text` and `validate_vector` enforce the same public constants used by bounded serde visitors. Add and Set commands therefore cannot create a project that saves successfully but fails to decode because one field or path exceeded its wire limit. The regression executes exact and one-over payloads through `Editor::execute`, verifies failed commands leave document/generation unchanged, and round-trips accepted text, path-count, and command-count boundaries through `save_project` and `load_project`.

## Candidate-document preflight keeps failure paths recoverable

Semantic Add and Set mutations are validated as complete candidate documents before the editor swaps state or records history. Hidden nodes receive semantic preflight during project validation, so visibility cannot defer an over-budget payload until a later edit or render. Rasterization checks the stored-raster ceiling before producing pixels; the exact-quota and next-allocation fixture confirms the failed command preserves document and generation.

## Qt editing exposes only lossless semantic capabilities

Local projection retains text source, font identity, origin, size, and color, and `LayerModel::semanticSource` returns immutable source maps for text and recognized rectangles. Rectangle recognition requires both fill and stroke because `setVectorRectangle` always emits both; fill-only and stroke-only rectangles are projected as valid vectors without the edit capability. Native smoke and FFI fixtures exercise full-source text edits, immutable accessors, two-paint rectangle edits, and optional-paint capability narrowing.

## Network context and proposal admission remain separated from local source

The hosted system prompt is built from `agent_layers_value`, whose text summary contains byte, character, and line counts plus style metadata but not `text` or `preview`. The privacy regression invokes the production prompt builder and verifies a sentinel remains local. Proposal context carries aggregate semantic usage and existing IDs, so replacement arithmetic and deterministic collision probing happen before a proposal is accepted.

## Deterministic rendering and distribution boundaries remain intact

Filled open subpaths close consistently, post-`Close` commands require a new `MoveTo`, paintless paths reject before render work, and rasterized semantics match live semantics over opaque nested backdrops across blend modes. The installed executable is accompanied by byte-identical `LICENSE` and `THIRD_PARTY_NOTICES.md`, including the pinned font notice.
