## Command proposals record entries while undo and redo navigate them

`redrob_agent_propose` snapshots the editor without executing an action. `EditorBridge::applyProposal` rejects stale generation/document-epoch pairs and applies exactly one selected command, undo, or redo; no proposal path opens a core history group (`crates/redrob-ffi/src/abi.rs:443-505`; `native/qt/EditorBridge.cpp:1379-1420`).

Commands reach `redrob_editor_execute_json` and `Editor::execute`, whose ungrouped `History::record` pushes one undo entry. Approved undo/redo reach the corresponding C ABI operations and move an existing entry between core's undo and redo stacks (`crates/redrob-ffi/src/abi.rs:509-572`; `crates/redrob-core/src/editor.rs:159-169, 448-518`; `native/qt/EditorBridge.cpp:405-431`). `docs/architecture.md:17` and `docs/compatibility.md:24` now describe those behaviors separately, closing the prior documentation drift.

## Wide-tree rendering and Agent hierarchy destinations remain bounded

Rendering preflights checked operation counts for output initialization, visible raster composites, and each isolated group's clear/composite pair, then rejects pixel visits above `MAX_RENDER_PIXEL_VISITS` before output or intermediate allocation (`crates/redrob-core/src/render.rs:28-86, 159-187`). The 1,024² regression accepts exactly 256 Mi pixel visits and rejects the first valid group over budget (`crates/redrob-core/tests/editor_core.rs:1622-1652`).

Agent context derives destination depth from the target parent and subtree height from descendants. Add-group and move-node conversion reject over-depth destinations, while core repeats hierarchy validation transactionally (`crates/redrob-ffi/src/graphics_tools.rs:1022-1048, 1594-1667`). Regressions retain exact-limit add/leaf/subtree moves, one-over rejection, exact top/bottom same-parent movement, and transactional first-invalid-index rejection (`crates/redrob-ffi/src/graphics_tools.rs:3129-3227`; `crates/redrob-core/tests/editor_core.rs:1779-1865`).

## Selection-authored masks still reach production QML and history
