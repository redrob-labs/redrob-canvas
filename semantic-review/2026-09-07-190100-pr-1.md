# Native Qt/QML safety and rendering hardening

The follow-up closes the unsafe rectangle cast, lossy padding, proposal replay, unbounded contour, off-viewport checkerboard, and unasserted smoke paths from the previous review. Selection publication no longer rebuilds `CanvasItem` caches when the mask is unchanged, pressure enters through `PointHandler`, and the Indexed8 tint is visibly alpha-composited in the offscreen capture. Three gaps remain: failed refresh advances the public generation without the projected snapshot, unrelated edits still copy and compare the complete selection mask, and zero-pressure pen samples become full pressure.

**Watch for:** **High, confirmed** — commit-with-refresh-failure creates a mixed-generation bridge state with no retry; **Medium, confirmed** — every edit still allocates, copies, and compares the full selection mask; **Medium, confirmed** — valid zero-pressure non-mouse samples become pressure `1`.

**Verdict**: NEEDS_CHANGES

## High-level view

Rectangle helpers reject non-finite or out-of-range values before integer conversion, while crop, resize, and padding enforce both the 32,768-side and 64-Mpixel limits. Padding computes the complete target first, so an impossible request is rejected rather than narrowed into a crop that loses the source.

Mutations return success once the core commits, allowing proposals to be consumed even when snapshot publication fails. **High, confirmed:** the failure branch writes the committed generation into `m_generation` while render, layer, selection, history, and dimensions remain from the old snapshot, then offers no projection-only retry.

Selection publication is content-gated, and contour geometry has an exact 262,144-segment ceiling followed by a bounded 65,536-cell fallback. **Medium, confirmed:** `EditorBridge::refresh` still deep-copies and compares the full selection mask after unrelated edits because `ChangeSet.selection_changed` is discarded.

Checkerboard iteration uses the visible painter clip, and the one-byte Indexed8 overlay preserves palette alpha on the tested Qt software path. `PointHandler` supplies tablet pressure and cancellation clears pending strokes, but **Medium, confirmed:** valid pen pressure zero is treated as unavailable and sent as full pressure.

The native target is registered through CTest, and smoke mode asserts generation advancement, active selection, mask dimensions, nonempty coverage, root creation, and screenshot output. The build, registered smoke, direct smoke run, and Rust workspace tests pass; the capture visibly contains the translucent tint and contour.

## Core commit can outrun the published projection

`applyProposal` now removes a proposal after FFI commit even if display refresh fails, eliminating the replay path (`native/qt/EditorBridge.cpp:361-370,388-398,1222-1232`).

**High, confirmed:** both mutation paths then assign the committed `ChangeSet` generation to `m_generation` and emit `documentChanged` on refresh failure (`native/qt/EditorBridge.cpp:364-370,391-398`). The matching render image, layer model, selection mask, dimensions, and undo/redo flags are replaced only after a coherent snapshot succeeds (`native/qt/EditorBridge.cpp:872-895`). The bridge can advertise generation N while exposing projection N-1, and a new proposal can be stamped for N despite describing state that is not visible. No timer, queued invocation, or public path retries `refresh`; the stale projection can persist until another mutation happens to refresh it.

Keep committed generation separate from projected generation, consume the proposal on commit, gate editing and proposal creation while projection is stale, and schedule a projection-only retry. Publish `m_generation` and `documentChanged` only with the coherent snapshot.

## Selection invalidation stops at the QML boundary

The equality gate prevents unrelated edits from republishing the mask or rebuilding the Indexed8 overlay and contours. **Medium, confirmed:** the bridge still calls `redrob_editor_selection_mask`, deep-copies the borrowed mask, and performs a full-image comparison on every refresh (`native/qt/EditorBridge.cpp:828-858,872-875`). Command and history paths retain `ChangeSet` only long enough to extract `generation`; they never inspect `selection_changed` (`native/qt/EditorBridge.cpp:23-33,361-364,388-391`). A legal 64-Mpixel document therefore incurs a Rust snapshot allocation, 64-MiB C++ copy, and 64-MiB comparison after a brush, filter, layer rename, or visibility change.

Parse invalidation flags with generation and reuse the current selection projection when `selection_changed` and canvas replacement are false. Initial load, document replacement, canvas-size changes, and history actions whose `ChangeSet` marks selection changed must still request it.

## Bounded contours, visible checkerboard, and Indexed8 tint

The contour builder keeps exact edges until the 262,144-segment budget, then discards the partial path and rebuilds from an occupancy grid capped at 65,536 cells (`native/qt/CanvasItem.cpp:14-15,208-239,241-304`). The Indexed8 overlay carries a 256-entry alpha palette (`native/qt/CanvasItem.cpp:188-198,363-365`); the captured smoke frame shows checkerboard through the tint, so alpha rendering works on the tested Qt 6.12 software backend. Checkerboard bounds come from `target ∩ boundingRect ∩ painter clip`, limiting tile loops to visible cells (`native/qt/CanvasItem.cpp:339-360`).

## PointHandler cancellation is sound, but pressure zero is not

`PointHandler` commits once when active becomes false and routes handler cancellation, Escape, and tool changes through `cancelStroke` (`qml/Main.qml:35,139-142,319-408`). **Medium, confirmed:** `pointPressure` returns the measured value only when it is strictly greater than zero; finite zero from a pen falls through to `1` (`qml/Main.qml:331-338`). Zero is inside the pressure contract and can occur at contact/release boundaries, producing a full-pressure endpoint rather than a zero-pressure endpoint.

Keep `1` as the explicit mouse/touchpad fallback, accept and clamp every finite non-mouse value in `[0, 1]`, and add a pointer test for zero, fractional, mouse fallback, cancellation, and one-commit-per-gesture behavior.

## Asserted CTest smoke reaches the rendered canvas

Smoke mode fails unless generation advances, selection is active, mask dimensions match, and at least one mask pixel is selected; it later requires a QML root and successful window capture (`native/qt/main.cpp:52-89`). CTest registration supplies offscreen/software settings and a timeout (`native/CMakeLists.txt:5`, `native/qt/CMakeLists.txt:76-81`).

`cmake --build build/qt-6.12 --parallel 2`, `ctest --output-on-failure`, a direct offscreen smoke run, and `cargo test --workspace` all pass. Not tested: injected refresh failure, selection invalidation cost, contour fallback limits, and pressure/cancellation behavior.
