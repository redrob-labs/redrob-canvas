## High-level view

`EditorBridge` stages document metadata, layers, render output, and any required selection snapshot, publishing only after dimensions, layouts, and generations agree. A failed post-commit refresh marks the bridge stale and starts a projection-only timer without changing the public generation or projections.

The parsed `ChangeSet` determines whether selection is captured. Selection and canvas invalidations request a fresh mask; unrelated mutations retain the mask and active state, while initialization, document replacement, null-mask recovery, and selection-requiring retries still capture it.

Mouse and touchpad input use full-pressure fallback, while every finite non-mouse value is clamped into `[0, 1]`. Smoke mode invokes the production QML normalizer for stylus zero, stylus `0.35`, and mouse fallback before exercising selection rendering.

## Atomic projection publication after committed mutations

Command and history paths derive capture from `selection_changed || canvas_changed`, call `refresh`, and schedule a retry only after commit and synchronous projection failure (`native/qt/EditorBridge.cpp:370-430`). `scheduleProjectionRefresh` sets the stale gate before starting the repeating 250 ms timer and preserves any pending selection requirement; the timer calls only `refresh` (`native/qt/EditorBridge.cpp:102-114,813-819`).

`refresh` keeps candidate state local while validating dimensions, buffer layouts, and matching document/layer/render generations plus selection generation when captured. Only then does it update `m_generation`, dimensions, history flags, layers, images, and selection state before clearing both retry flags and stopping the timer (`native/qt/EditorBridge.cpp:821-945`). Every failure path therefore leaves the prior coherent snapshot published.

The stale gate covers commands, undo/redo, stroke starts, file replacement, local/live proposal creation, asynchronous proposal completion, and proposal application (`native/qt/EditorBridge.cpp:370-443,947-982,1040-1055,1175-1222,1299-1336`). Commits and refresh run synchronously on the GUI thread, so an existing stroke cannot interleave another mutation before stale state is established. Failed timer attempts retain the accumulated selection requirement and remain active; success stops the member timer.

## Selection invalidation and retained-mask safety

`ChangeInvalidation` requires both boolean flags and falls back to conservative selection/canvas invalidation on malformed data (`native/qt/EditorBridge.cpp:21-47`). The core marks selection commands and canvas resize/crop, and undo/redo preserve that metadata (`crates/redrob-core/src/editor.rs:197-345`). Initialization and file replacement explicitly request selection, while `refresh` forces capture when no mask exists.

When capture is skipped, `redrob_editor_selection_mask` is not called and no selection `QImage` is constructed or compared. The retained mask dimensions must still match the candidate document, and its active flag remains paired with it (`native/qt/EditorBridge.cpp:825-932`). Captured selection validates dimensions, layout, generation, active state, and bytes before publication.

## One-shot proposals across refresh failure

Proposal application validates projected generation and document epoch before dispatch. Core success removes the proposal even when projection fails, and the resulting stale gate prevents another apply until retry publication succeeds (`native/qt/EditorBridge.cpp:1299-1336`). Successful import/load increments the document epoch and requests a complete selection snapshot, so pre-replacement proposals remain stale through any retry interval (`native/qt/EditorBridge.cpp:947-982`).

## Shared QML pressure normalization and asserted smoke coverage

`normalizedPressure` returns `1` for mouse/touchpad, clamps every finite pressure from other devices, and uses `1` for non-finite fallback (`qml/Main.qml:331-342`). Stroke start and continued points both delegate to it (`qml/Main.qml:365-392`). Native smoke invokes that same QML function for stylus `0`, stylus `0.35`, and mouse `0`, requiring results `0`, `0.35`, and `1` (`native/qt/main.cpp:25-49,73-81`).
